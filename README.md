# Authenticator

A Flutter application demonstrating user authentication using Firebase.

## Firebase Configuration

The `starter` folder contains the starter project.

The `final` folder contains the completed project, which uses Firebase Authentication.

**Before running the final project, connect it to your own Firebase project:**

1. Create a Firebase project.
2. Add a Flutter application.
3. Configure Firebase for Android and iOS using the FlutterFire CLI.
4. Enable **Email/Password** authentication in the Firebase Console or using CLI:

```
firebase init auth
```

**Note:** Firebase configuration files are excluded from this repository. You must generate your own configuration files using your Firebase project.
